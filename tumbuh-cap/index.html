Tumbuh Cap

A small machine for keeping ecological distinctions honest. Clean water remains clean. Organic matter enters a removable living chamber. Gravity carries moisture and soluble nutrients toward the roots. Every hidden process must have a visible service point.

The pilot

Prove the plumbing before inviting the ecology.

The first successful artifact is not a thriving autonomous planter. It is a boring, inspectable cap that does not leak across its own distinctions.

Clean: measured water, soft tube, replaceable grommet.

Living: coarse mesh, washed biochar, leaf litter, then microbes.

Root: visible gravity drainage into a sacrificial planter or catch vessel.

Print the coupon

Validate grommet diameter, cartridge clearance, and slicer behavior with a tiny part.

Run dyed-water isolation

Put dye in one channel only. Any color crossing the boundary is an immediate failure.

Measure gravity flow

Record first drip, 5-minute, 15-minute, and 30-minute output for a 50 mL input.

Add complexity one layer at a time

Biochar, leaf litter, finished compost, microbial pilot—and only later, considered habitat.

Fredericksburg fabrication loop

Designed around a real place.

IdeaSpace gives the project a concrete production rhythm: train on the printer, carry the actual fittings to the machine, print the fit coupon first, then use short revision loops rather than betting the whole design on one long print.

The source is already parametric. Change part = "test_coupon", export an STL, and arrive with the tube, grommet, mesh, pot, and calipers. The page is not the product; the measured revision history is.
